# Cantinho Doce · Pousada & Camping Club

Site institucional do Cantinho Doce, pousada e camping à beira do Rio Macaé em Lumiar, Nova Friburgo (RJ).

Publicado em: https://igorstutz.github.io/camping-cantinho-doce/

## Estrutura

- `index.html` — página única com todas as seções
- `css/style.css` — estilos
- `js/data.js` — dados das acomodações (nomes, valores, comodidades, fotos)
- `js/main.js` — interações (menu, slideshow, modal, lightbox)
- `img/lg` e `img/sm` — fotos otimizadas em WebP (1600 px e 900 px)

Para atualizar valores ou comodidades de uma acomodação, edite apenas `js/data.js`.
